## 已核实的依据

- [tsnet 官方文档](https://tailscale.com/docs/features/tsnet)：Go 库、用户态网络栈，可通过 auth key 代替浏览器登录；内嵌节点与系统 Tailscale 节点不同。
- [OAuth client 官方文档](https://tailscale.com/docs/features/oauth-clients)：服务端可生成带限定权限的注册凭据；具体 scope、tag 和设备生命周期须按选定版本验证。
- [服务条款](https://tailscale.com/terms)第 2.1、2.3 节：标准服务用途与商业利用、转售及竞争性用途存在限制。本项目模式是否获准须取得书面答复；本记录不是法律意见。
- [Tailscale 客户端 LICENSE](https://github.com/tailscale/tailscale/blob/main/LICENSE)：客户端开源授权与托管服务合同分开核查；发布时还须清点第三方依赖许可证。
- [Headscale 项目](https://github.com/juanfont/headscale)：可作为自托管控制面的候选；不能仅凭其存在就推定 tsnet 版本兼容、多租户隔离、运维和中继已解决。

## 候选路线及决策门

| 路线 | 用户免登录 | 核心验证 | 决策条件 |
| --- | --- | --- | --- |
| tsnet + 托管 Tailscale | 通过后端注册可望实现 | 已排除 | 用户确认许可/费用不适合 |
| tsnet + 自托管控制面/DERP | 可望实现 | 当前优先验证版本兼容、控制面、隔离、中继和运维 | 本机试验后再验收跨网，不视为零成本替代 |
| 自有寻址 + 直连/中继 | 可设计实现 | 穿透成功率、端到端认证、传输和运维成本 | 前两条不满足产品要求时再决定 |

优先做 tsnet 独立进程原型，显式指定自托管控制服务器，关闭客户端日志上传；Headscale 的 DERP map 仅提供本项目中继，不引用托管公共 DERP。原型在 `poc/selfhost`，独立于产品 Swift/C#，当前仅允许本机控制面地址。

## 现有代码接入点与原型设计

Mac `TLSControllerClient.swift` 使用 `NWConnection`；Windows `TlsProbeServer.cs` 使用系统 `TcpListener`。tsnet 的虚拟网络位于 Go 进程，不能假定系统 socket 能直接访问其地址。

原型进程提供两种角色：控制端将本地应用连接转入 `tsnet.Server.Dial`；被控端用 `tsnet.Server.Listen` 接收连接并转入本地服务。双向转发原始字节，应用 TLS 在原始端点间完成，桥接不终止 TLS、不接触剪贴板/屏幕明文。

PoC 初期仅固定小载荷 ping/echo，不接 SendInput，不修改现有产品监听地址校验。将来接产品时必须设计专用本地桥接入口：loopback 不能作为可信身份，不能简单删除现有 Tailscale 对端检查。需要限制本地进程访问、校验会话授权，保留 TLS 指纹/HMAC，测试其他本地进程连接及伪造目标拒绝。设备码不能直接作为受信任 IP 或 TLS 身份。

原型用独立状态目录，权限仅当前用户；不共用或清理系统 Tailscale 状态。注册凭据经受限 IPC 传入，不放命令行、仓库、安装包或日志；OAuth secret 只在后端。输出仅固定状态/错误码和必要元数据。

正式验证码流程由后端将设备公钥、目标、权限、到期时间和一次性 nonce 绑定到授权；被控端验证并批准后才接受会话。短验证码只用于定位/证明邀请，不直接派生现有 32 字节长期密钥。第一版后端模拟不能标为真实免登录注册通过。

## 分步交付与验收

| 步骤 | 交付 | 通过依据 |
| --- | --- | --- |
| A | 固定依赖版本、Go helper、隔离 IPC、固定载荷 | Mac 本机双进程测试、非法请求/目标拒绝、退出与泄漏检查 |
| B | 三平台构建及本机运行 | macOS Intel/Apple Silicon、Windows x64、Linux x64；交叉编译不代替运行 |
| C | 后端注册与设备码/验证码原型 | 无外部 Tailscale 登录、验证码到期/重放/限速、被控端拒绝与撤销、重启身份稳定 |
| D | 双机网络和隔离验证 | 热点/不同网络直连、受限网络中继；A→B 获准、A→C 拒绝；撤销关闭已有流和后续连接 |
| E | 接现有 TLS 的固定数据验证 | TLS/指纹/HMAC 仍端到端、第二客户端拒绝、helper 崩溃/重启清理、不复活旧授权 |
| F | 架构结论 | 技术证据、候选许可证/成本结论、已知限制齐全后决定底座；托管商务路线已排除 |

网络策略默认拒绝，不能让所有客户进入同一个允许互通的 tailnet。需验证按会话只开放指定设备对/端口，授权撤销与已打开连接的关闭分开处理；不假定修改 ACL 或撤销注册 key 就能立即结束活动连接。

## 托管商务确认材料（历史；路线已排除）

对 Tailscale 合作方说明：独立 Win/Mac/Linux 远控软件，第三方终端用户免 Tailscale 账号，应用内嵌 tsnet，通过运营方后端注册，用户设备码配对且有人值守批准；有加密屏幕和输入流，可能产生持续 DERP 带宽。

需要书面答复：

1. 此产品、分发、代注册和第三方用户模式是否允许；需要 OEM/合作合同还是普通商业方案。
2. 按用户、节点、活跃设备还是其他单位计费；100/1,000/10,000 节点的限额与报价。
3. 高频短期设备、tag、OAuth/API 调用和多租户隔离的限制，是否推荐独立 tailnet。
4. DERP 视频流的政策、配额、地区、计费及是否允许自建 DERP；高并发支持方式。
5. tsnet 支持承诺、兼容性、SLA、故障响应及终止服务后的迁移路径。
6. 白标、品牌、隐私/设备元数据地域、数据处理协议及用户告知要求。

本代理没有发送邮件/表单、签合同或购买资源。用户现已回报许可/收费不可接受，本路线关闭，不再等待托管商务答复。

自托管组件的 Tailscale 客户端与 [Headscale v0.29.4 LICENSE](https://github.com/juanfont/headscale/blob/v0.29.4/LICENSE) 均为 BSD-3-Clause；发布需保留版权和许可证声明，不借用第三方品牌背书。依赖许可证清单、实际流量成本和公开部署方案仍待后续发布审查，不把客户端 BSD 许可解释为托管服务使用授权。

成本先用可审查公式，不虚构报价：中继流量 GB = 中继会话小时 × 平均 Mbps × 0.45（十进制 GB，不含额外协议开销）；再乘实际计费流量单价，计入中继占比、双向/出口计费口径、节点费用及控制面运维。720p/更高画质先按实测码率建模。
