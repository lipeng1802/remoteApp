# 独立远程桌面产品路线

2026-09-29 用户确认：最终面向其他用户提供接近 AnyDesk 的独立安装和连接体验。该目标扩大长期产品范围；当前先完成 Mac 控制 Windows 的基础链路。

## 最终用户体验

两端安装并启动应用，Windows 展示设备标识和连接状态，Mac 输入设备标识或邀请信息发起连接；Windows 明确确认访问，用户可随时停止。普通用户无需配置 SSH、复制终端命令或自行配置第三方组网工具。设备信任、授权撤销、网络失败、升级和卸载都有图形界面流程。

这是最终目标，不是当前产品已具备的能力，也不承诺功能范围与 AnyDesk 完全相同。

## 实施顺序

2026-10-05 优先级调整：已验证的剪贴板切片收口后，先在独立分支完成 [免 Tailscale 登录连接架构 PoC 与商业可行性](CONNECTION_ARCHITECTURE_POC.md)。以下原顺序作为长期范围参考，独立连接架构决策提前到自动重连、外部 Tailscale GUI 集成、H.264 和多平台角色开发之前。物理键盘/干净机器验收保留，正式签名按用户要求延期，不伪装成已完成。

1. **现有基础链路**：完成 P1 画质与稳定性；完成 P2 输入预览、认证 TLS mock、真实键鼠和本机停止验收。开发阶段继续使用 Tailscale。
2. **可供小范围测试的安装版**：图形配对、可信设备管理、认证失败退避、断线重连、诊断导出、签名、公证、版本升级与干净机器安装/卸载。验证 4 小时耐久；H.264 按原 P4 单独安排。
3. **独立连接架构**：设计设备注册/身份、短期邀请、信令、直连探测与中继回退；先完成威胁模型、连接协议和服务成本估算，再实现服务。账户是否必需、有人值守与无人值守模式分别设计。
4. **独立连接实现与试用**：客户端显示直连/中继状态，处理服务不可达与连接失败；跨运营商/热点/受限网络验证。服务只承担寻址与转发，端到端加密与设备认证保持独立。
5. **对外发布**：代码签名/公证、可信更新与失败回退、最小诊断数据、明确隐私说明、滥用处理、依赖许可证核查、服务运维和支持流程；从有限用户试用开始。

## 当前范围

2026-10-06 邀请后端更新：已完成独立本地授权核心/HTTP fixture 的设备码、短期邀请、确认/拒绝、签名授权和持久化安全边界。下一切片是把受控后端接入双机固定载荷，验证应用设备身份到 Headscale 节点绑定及撤销闭环；不是直接开放当前注册服务或发布新产品包。

2026-10-06 第二公网切片更新：真实直连、新连接中继回退、被控端私有管道撤销活动授权已得到固定载荷证据，注册 key 撤销与会话关闭分别检查。接下来优先设备码/短期邀请后端及到期/重放/限速/撤销持久化，再接产品 TLS 桥接。已打开连接无缝路径迁移、跨运营商覆盖率、生产运维和多平台仍不计通过。

2026-10-06 范围更新：用户另行授权使用自有服务器/域名和放行 PoC 端口，已完成隔离公网部署与 Windows serve / Mac probe 自建中继固定载荷验收。连续客户端/服务端重启、拒绝未授权节点、正常退出与测试凭据清理通过。下一步优先直连/中继回退、撤销活动流，再做设备码邀请与产品 TLS 桥接。下方“不做公网部署”是 10-05 初期边界，已被本次明确授权更新；仍不扩展为生产服务、购买资源或真实公网键鼠。

2026-10-05 新决策：托管 Tailscale 因用户回报商业许可/费用不合适而排除。优先实验 tsnet + 自托管 Headscale/DERP，保持现有产品不变。首轮退出与重连故障已有隔离修复：更换强制中继调试模式、禁用缓存网络图功能并保持原身份；完整回归纳入双端重启后的数据交换与正常关闭。仍是候选而非最终架构。下一步各平台独立 helper 实体运行，然后授权后端/真实 TLS 桥接；暂不做公网部署。

当前产品已完成 Mac 控制 Windows 和显式双向纯文本剪贴板的用户验收。下一步允许在隔离 PoC 中研究设备身份、邀请和嵌入式传输；正式账户服务、服务器部署、资源购买及防火墙变更不在本次范围。PoC 初期只传固定测试载荷，不开放公网输入控制。

现有 Tailscale 寻址与应用 TLS/HMAC 可继续支撑早期验证；后续独立网络发现应与认证/视频/输入协议解耦。开发用 SSH 仅为诊断通道，不作为最终用户依赖。

2026-10-02 集成决策：MVP 不将 Tailscale 后台或 macOS 系统扩展重打包进本项目安装器。短期集成定义为 GUI 检测官方客户端的安装、登录和在线状态，并提供明确的安装或登录入口。完整内嵌需单独评估官方 Go tsnet 边车、每个应用独立节点身份、登录/注销、状态保护、升级、平台权限及许可证；该工作属于独立连接架构，不与当前安装包收尾混合。

下一任务按 [P2 输入交接](P2_INPUT_HANDOFF.md) 继续；当前阻塞和实际测试以 [HANDOFF](HANDOFF.md) 顶部为准。
